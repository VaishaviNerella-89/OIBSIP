# Nova - Python Voice Assistant

## Project Description

Nova is a Python-based voice assistant developed as part of the Oasis Infobyte internship Task 1.

The assistant listens to spoken commands, converts speech into text, processes the command, and responds using text-to-speech.

## Features

- Voice input using SpeechRecognition
- Text-to-speech using pyttsx3
- Greeting responses
- Current time and date
- Web search
- Weather information
- Timer/reminder
- General knowledge questions
- Natural-language command processing
- Custom commands
- Handles commands that are not understood

## Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- Requests
- datetime
- webbrowser
- JSON
- threading
